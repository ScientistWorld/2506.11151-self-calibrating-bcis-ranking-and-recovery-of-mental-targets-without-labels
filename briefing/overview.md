# Overview

This reproduction implements CURSOR from “Self-Calibrating BCIs: Ranking and
Recovery of Mental Targets Without Labels.”

- **Paper ID:** 2506.11151
- **Title:** Self-Calibrating BCIs: Ranking and Recovery of Mental Targets
  Without Labels
- **Domain:** Brain-computer interfaces / EEG target recovery
- **TL;DR:** The paper ranks possible mental targets from unlabeled
  EEG-stimulus interactions by testing which candidate makes the observed brain
  responses internally predictive of candidate-specific distances.

## Short Summary

The benchmark asks a solver to rank 60 candidate face latents for a hidden
mental target using only one session's paired stimulus latents and real EEG
responses. Sessions are generated by the evaluator. Stimuli and candidates are
drawn independently of the target, so only the EEG/stimulus pairing carries the
answer. Solvers are registered commands that the evaluator runs on visible
train sessions and on hidden test sessions.

## Key Results (hidden test, 48 sessions per experiment)

| Experiment | CURSOR-LR rank / top-rank distance | S-LR | Dummy (chance) |
|---|---|---|---|
| raw EEG, N = 3000 | 2.69 / 3.89 | 31.2 / 22.9 | 30.5 / 22.5 |
| EEGNet, N = 3000 | 2.52 / 6.06 | 29.4 / 23.6 | 30.5 / 22.5 |
| raw EEG, N = 1000 | 14.94 / 15.39 | 29.9 / 21.0 | 30.5 / 22.8 |

On the paper's own simulation protocol at full scale (N = 9234), CURSOR-LR
ranks the target first in all 34 runs. A no-EEG stimulus-centroid ranking
nearly matches it (rank 1.03), which is why the scored sessions use a
target-independent geometry (see `HARDENING.md`).
